# Marketplace Positioning

## Category

Project management, productivity, engineering operations, launch management.

## One-Liner

SignalRoom predicts hidden project risks from Slack conversations and connected work tools.

## Target Users

- product teams preparing launches
- engineering teams managing releases
- agencies coordinating client delivery
- startup founders tracking execution risk
- operations teams running cross-functional projects

## Differentiation

Existing project tools track explicit work. SignalRoom detects implicit work risk from conversations: promises, contradictions, missing owners, stale blockers, and overloaded people.

## Slack-Native Moments

- Ask in-channel: "Are we ready to launch?"
- Post a risk radar to the project channel.
- Convert risk findings into a rescue brief.
- Cite the messages and docs behind each signal.
- Run what-if simulations without leaving Slack.
